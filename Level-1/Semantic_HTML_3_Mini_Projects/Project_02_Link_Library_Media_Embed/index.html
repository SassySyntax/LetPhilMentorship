Best practices for links

  • Use meaningful link text
  • The href attribute ensures the anchor tag is keyboard-accessible, and has semantic meaning
  • Use anchor tags for navigation, and buttons for actions (i.e., "Submit", "Login")
  • Use relative URLS for internal links (i.e., "/about")
  • The rel value "noopener noreferrer" improves privacy and prevents security vulnerabilities via window.opener
  • Use aria-label attribute on links with icons (image) for content

Descriptive links help accessibility because they provide context for screen readers. A question to ask is, does the link have a purpose, destination, or expected outcome?
